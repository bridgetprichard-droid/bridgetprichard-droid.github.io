Expense Reporting App

I built a custom application to help an organization record expenses and prepare reports.

I used OpenAI Codex to build the tool around the reporting task. I designed the workflow around the tasks staff need to complete. They can record an expense and check the entries before exporting a report.

What to look for

Use the sample data to add an expense, filter the records, and generate a report. The CSV includes the same records and total shown in the report.
